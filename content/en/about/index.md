<div class="profile-bio">
<p>CNCF Ambassador, AAIF (Agentic AI Foundation) Ambassador, and Kubestronaut. I apply and teach Kubernetes, Cloud Native, and Agentic AI in the field, and when that work raises a question with no reference data, I measure it myself. So far those questions have centered on Kubernetes: how much a CNI (Container Network Interface) uses at idle, how Gateway API implementations differ, and how well AI agents handle cluster incidents. More recently I have started looking at what changes when you put a gateway in front of MCP (Model Context Protocol) servers or connect agents to each other over A2A (Agent2Agent). Separately, I have written five technical books, spoken at KubeCon + CloudNativeCon Europe, North America, China, India, and Japan, and served on the program committee for those same events since 2023. KubernetesLab is where those measurement results and field notes live.</p>
